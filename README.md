## 📌 About The Project

**Notes Hub** is a college resource management website developed to make academic resources easily accessible to students.

The platform provides a centralized place where students from different departments, including Information Technology (IT), Computer Science (CS), Data Science (DS), and other departments, can access and download study materials.

Instead of searching through multiple sources for notes and academic resources, students can use Notes Hub to find relevant study materials, access previous year question papers (PYQs), and explore additional learning resources in one place.

The primary goal of this project is to simplify the learning experience, encourage collaborative learning, and make educational resources more accessible to students.

## ⚙️ Installation & Setup

Follow these steps to run Notes Hub on your local machine.

### Prerequisites

Make sure you have installed:

- PHP
- MySQL
- XAMPP or a similar local server environment.
- Git

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project Directory

```bash
cd Notes-Hub
```

### 3. Set Up the Local Server

- Install and open XAMPP.
- Start Apache and MySQL.
- Move the project folder into the `htdocs` directory.

### 4. Configure the Database

- Open phpMyAdmin.
- Create a new database.
- Import the project's SQL database file, if available.
- Update the database connection settings in your PHP configuration file.

### 5. Run the Project

Open your browser and navigate to:

```text
http://localhost/Notes-Hub/
```

Your Notes Hub application should now be running locally.
